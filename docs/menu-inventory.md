## Data rules

- 2 main navigation groups (Drinks and Food), containing 8 categories and 69 listed product/menu entries. **One dedicated webpage per category per language**, no individual product pages.
- This file preserves the supplied Arabic and English wording and order. Names, spellings, and size labels have **not** been editorially changed.
- Product size suffixes `S`, `D`, `M`, `L` are preserved exactly as supplied. **Do not assume** `D` means Double or that size labels are consistent across products without a verified menu sheet.
- The user listed `Espresso S` and `Espresso D`, and `Macchiato S` and `Macchiato D`, as separate entries. They count separately in the 69 entries; whether to combine them into variants of one product is **TBD**.
- Where no size is given, size applicability is **unknown**, not necessarily single-size.
- All item prices, calorie values, ingredient lists and image paths are **TBD**, with calorie/price values to be stored per applicable variant.
- The two parent groups are **Menu sections**, not additional standalone web pages or XML sitemap URLs.
- Slugs below are **proposed placeholders** for URLs, not approved production URLs. No approved subcategory division has been provided.
